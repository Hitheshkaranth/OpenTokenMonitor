# Hitheshkaranth/homebrew-tap

Homebrew casks for [OpenTokenMonitor](https://github.com/Hitheshkaranth/OpenTokenMonitor) — a local-first usage limit and cost monitor for Claude Code, Codex and Antigravity.

## Install

```bash
brew install --cask hitheshkaranth/tap/opentokenmonitor
```

Upgrade with `brew upgrade --cask opentokenmonitor`. Uninstall with `brew uninstall --cask opentokenmonitor`; add `--zap` to also remove the app's local database, logs and settings.

The cask is updated automatically when a new OpenTokenMonitor release is published.
